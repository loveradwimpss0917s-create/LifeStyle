**原因の特定(ローカル実測で確定):**

```
上位リソース(転送量・優先度)
  1119KB Font       VeryHigh  zen-kaku-gothic-new-cjk-400.woff2  ← 単独で全体の8割
```

モバイル実効帯域(PSIのSlow 4G ≒ 200KB/s)では 1119KB ≒ **5.6秒**。観測されたFCP 6.6秒とほぼ一致する。

`src/styles/fonts.css` のコメントには、unicode-range分割(@font-face 120個)がスタイル再計算を
招いたため統合フォント1本に置き換えた経緯と「Performanceが100前後まで回復」との記録があるが、
**これはdesktop条件での測定**であり、モバイル帯域での転送時間は解決されていない。
`font-display: swap` と「CJKフォントにpreloadを付けない」判断は正しく実装されているが、
インライン`<style>`内の`@font-face`から参照されるため、ブラウザは結局VeryHighで取りにいく。

## 4. 問題点の分類

### 🔴 Critical

**C-1. 検索インデックス0件 — サイトが検索エンジン上に存在しない**
- 事実: Search ConsoleのURL検査で「URLがGoogleに登録されていません」「参照元サイトマップが検出されませんでした」。
  サイトマップ送信から4日間ステータス変化なし。`site:` 検索でもヒットなし。
- 影響: SEO技術面が100点でも、流入は構造的にゼロ。他のあらゆる改善が意味を持たない前提条件。

**C-2. 1.1MBの日本語フォントがモバイル初期表示を約5〜6秒遅延させている**
- 事実: 単一WOFF2 1,119KB が VeryHigh 優先度で取得。本番モバイル FCP 6.6秒 / LCP 8.3秒。
- 影響: モバイルユーザーは6秒以上白画面を見る。Core Web Vitals の LCP は「不良」判定域(4秒超)。
  インデックスされた後のランキングに直接効く。

### 🟠 High

**H-1. CIの性能ゲートがdesktop限定 — モバイル劣化を永久に検知できない**
- 事実: `lighthouserc.json` の `preset: "desktop"`。モバイル計測はCIに存在しない。
- 影響: 本番モバイル59点でCIは緑。今後の劣化も検知されない。

**H-2. 商品ページ本文が224〜747字 — 最も購買意欲の高いページが最も薄い**
- 事実: 記事平均2,600字に対し商品ページ平均386字。
- 影響: 「商品名 レビュー」「商品名 口コミ」は購買直前クエリであり、本来最も強い集客・収益ページ。
  現状はアフィリエイトボタンの台座になっている。

**H-3. Cloudflare Web Analyticsの本番稼働が未確認、かつプライバシーポリシーは稼働を断定している**
- 事実: コードは環境変数依存。`privacy.astro` は「利用しています」と記載。本番設定は確認できない。
- 影響: 未稼働なら(a)一切計測できていない (b)記載と実態の不整合。どちらも早期に潰すべき。

## 8. 「今このサイトに100万円投資するなら」

現状のボトルネックは **技術ではなく、①発見されないこと ②中身の量 ③ブランド約束と実態の齟齬** の3つ。
技術投資のROIは既に低い(器はできている)。したがって配分は以下を推奨する。

| 順位 | 投資先 | 金額 | 理由 |
|---|---|---|---|
| **1** | **写真(実写差し替え + 今後の撮影体制)** | 30万円 | 「実際に買って使った」というブランド約束と実態の齟齬を消す唯一の方法。同時にメーカー画像の著作権リスクも解消する。競合が最も真似しにくい資産で、記事が増えるほど複利で効く |
| **2** | **コンテンツ制作時間の確保** | 30万円 | 1記事あたりの品質(2,500字超・実体験・気になった点あり)は既に高い。ボトルネックは純粋に本数。同じ品質で20〜30本に増やせば、カテゴリの網羅性・内部リンク・検索接触面が同時に改善する。外注ではなくオーナーの時間を買う投資(家事代行・一時保育等を含む)として使うのが最も効率的 |
| **3** | **独自ドメイン取得と移行** | 5万円 | `pages.dev` のままではブランド資産が積み上がらず、指名検索も育たない。移行は早いほど傷が浅い。技術的な移行作業自体は3ファイルの変更で済む |
| **4** | **モバイル性能の改善(フォント最適化)** | 10万円 | LCP 8.3秒 → 2秒台。インデックスされた後のランキングと直帰率に直接効く。ただしインデックスされるまでは効果が顕在化しないため3位以下 |
| **5** | **撮影機材・環境** | 15万円 | 写真カテゴリを立ち上げるなら必要。1位の投資と一体で考える |
| **6** | **計測・順位トラッキングツール** | 10万円 | データに基づく改善のため。ただし流入が発生してから契約する |

**投資しないもの(明確に推奨しない)**

- **AI自動生成の強化** — 記事7本の規模では、編集ワークフローによる手動執筆の方が品質・速度とも上回っている
- **新機能開発** — 診断・ランキング・お気に入り・検索は既に揃っており、使われていないのは機能不足ではなく訪問者不足が原因
- **広告出稿** — コンテンツが20本に満たない段階で広告を打っても定着しない。3位までを終えてから検討する

## 9. 結論

HIBISTACKは **「開店準備を過剰なほど丁寧に終えたが、まだ看板が誰にも見えていない店」** である。

- 内装(デザイン・a11y・回遊設計)、レジ(アフィリエイト配管・計測)、
  接客マニュアル(3段階編集ワークフロー)は、個人経営の水準を明確に超えている
- 一方、商品棚は7本、看板(検索インデックス)は未設置、
  入口のドア(モバイル初期表示6.6秒)が重い

したがって次の30日でやるべきことは、新しい機能でも新しい設計書でもなく、
**①インデックス申請 ②フォント削減 ③商品ページの中身 ④記事本数** の4点に尽きる。
